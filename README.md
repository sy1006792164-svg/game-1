# 风笺回廊 · 1.13 体验升级

离线回声路径微信小游戏。保留原生 Canvas 入口、三拍回声规则、999 封主线来信和现有存档。

## 微信开发者工具

1. 切换到需要验收的分支，将仓库根目录作为小游戏项目导入。
2. 使用现有 `project.config.json`。入口仍为 `game.js` → `src/main.js`，不需要 Cocos、浏览器适配器或 npm 构建。
3. 编译后从首页开始，或继续本机已保存的投递。

`npm run build` 只生成浏览器预览包，不是微信导入的前置步骤。请勿将预览工具、测试、输出截图或本机私有配置加入上传包。

## 本次体验升级

- 路线复盘：暂停、灯灭或送达后逐步回看实际操作。人物、三拍回声、收集、风口、纸桥、顺序来信、潮汐/回声门均来自同一规则引擎。
- 关键步跳转：快速找到收集、机关、道具、续灯与结果。视频续灯单独显示为不推进拍数的操作。
- 无损回看：只读取当前路线，返回原暂停或结果界面；不重新结算、不改变存档、不消耗撤回次数、不请求广告。
- 章节目标：首页显示当前投递所属章节、已完成封数和阶段进度。点击可定位本章；继续旧关时不会错误跳到主线最远进度。
- 下一步更清楚：显示恢复路线的已走拍数，送达后给出实际三星目标或下一枚邮票所需星光。最终三关章节与全通关有独立状态。
- 轻量画面：可以手动减少装饰粒子，保留操作反馈；与系统减少动态偏好、设备画面限制共同生效并保存在本机。
- 操作速查：设置中可随时查看玩法、预览、复盘和电脑操作，不必先进入一关。

复盘按原始记录重建路线，不展示系统解法。逐步回看的是“操作”，使用道具或续灯可能不增加“拍数”。同一次路线最多记录 4096 次操作，复盘最多保留 18 个稀疏状态快照。

## 操作

- 轻点相邻亮格移动，点脚下或“等一拍”等待。
- 长按亮格/等待按钮免费预览；松手不行动，再轻点才确认。
- 电脑方向键 / WASD 移动，空格等待，Z / 退格撤回，Esc 暂停。
- Tab / Shift+Tab 选择按钮，Enter 激活。
- 复盘中左右键逐步看，Home / End 跳首尾，PageUp / PageDown 跳关键步，Esc / 退格返回。

## 开发验收

需要 Node.js 18 或更高版本；核心检查不需要安装依赖。

```sh
npm run verify       # 单元/流程回归 + 999 关可解/源码/包大小检查 + 预览构建
node tools/check-ads.js
node tools/difficulty-qa.js
npm run preview
```

`verify` 不包含微信账户操作、上传或发布。广告测试使用隔离的 SDK 模拟，覆盖完成、取消、异常、重复回调、退后台、过期会话和输入/音频锁释放；不会请求真实视频。原生入口测试使用没有 DOM 的内存宿主验证 `game.js` 启动与前后台切换，也不等同于微信真机。

### 可选静态画面预览

在可使用 `@napi-rs/canvas` 的环境运行 `npm run preview:static`。脚本调用真实 Game 和 Renderer，以及仓库原版图集，在 `output/experience/` 生成 320×568 和 390×844 的首页、复盘、结算、暂停、设置画面。截图是 CPU Canvas 静态预览，不是浏览器或微信开发者工具截图。该可选依赖不进入原生运行包。

### 仍需微信环境验收

- 开发者工具实际打包大小；源码估算不能代替编译后大小
- 真机安全区、文字/触控、连续投递、前后台切换和低内存
- 当前账户的真实激励视频加载、关闭和奖励流程
- 平台审核、上传与发布

现有 AppID、广告位、排行榜标识和分享配置保持原样。所有送达成绩、星级、邮票和日邮程继续使用原存档；未新增赛季清档、跟踪或付费机制。
