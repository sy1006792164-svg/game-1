# 风笺回廊

竖屏、单人、回合制的原生微信小游戏。送信员收集橙色信笺，晚三拍的回声沿历史落点收集蓝色邮票，最后到达邮局。首页一个按钮开始或续玩；选关页提供 167 章 999 关主线，难度分阶段上升；23 枚主线邮票作为收藏。所有关卡免费重试，进度只保存在本机。

项目路径：`E:\work\game-1`　微信 AppID：`wxee6289f904a5d625`

## 运行

微信开发者工具打开本目录，项目类型"小游戏"，点击"编译"。`game.js` 直接加载 `src/main.js`，不需要 npm 安装、构建或数据库。

浏览器预览（与微信版共用全部规则和界面代码，本地进度相互独立）：

```powershell
cd E:\work\game-1
npm.cmd run preview
```

打开 http://127.0.0.1:8765 。方向键 / WASD 移动，空格等一拍，Z 撤回，Esc 暂停。

```powershell
npm.cmd test
npm.cmd run verify:levels
npm.cmd run check
npm.cmd run build
npm.cmd run release:check
```

`release:check` 在缺少真实广告位时会失败，这是明确的发布前检查。

全部 999 关已按原灯火预算逐步验证可三星通关，并通过从空存档连续通关的主流程测试，未调整难度。`verify:levels` 输出逐关路线和结果；`check` 与构建也会自动执行全量通关检查。详见 [全关卡可通关验证](docs/SOLVABILITY.md)。

## 开发环境自由选关

微信开发版（`envVersion === 'develop'`）与本机 `localhost` / `127.0.0.1` / IPv6回环地址的浏览器预览自动启用。选关页显示“开发环境”，999关均可点击；也可点“输入关卡号”，用数字面板或键盘输入1–999后开始试玩。

体验版、正式版、公网浏览器以及环境识别失败时均按正常通关进度解锁，不显示开发入口。开发进度和进行中路线使用独立存档，开发测试不会修改正式成绩。没有需要发布前手动关闭的配置开关，详见 [开发选关说明](docs/DEVELOPMENT-v8.md)。

## 玩法

- 每次有效移动或等待消耗 1 拍，撞墙不消耗，没有实时倒计时。
- 第 3 拍回声出现于起点，之后始终走在你三拍前的落点上；它只收蓝色邮票。
- 风格推动一次，最终落点记入轨迹；等待不触发风。灯格首次踏上补 3 拍，每盏一次。纸桥离开后碎裂，回声可通过。
- 信笺与邮票全收齐且到达邮局即胜；最后一点灯火抵达也算成功。
- 三星按关卡目标拍数评价，看广告续灯后最高二星。每程有 1～3 次撤回，越靠后越少。
- 难度分阶段上升，同一阶段内按最短路线由短到长排列：棋盘从 6×6 扩到 10×10，信笺与邮票最终各 6 枚，风口最多 4 处、一次性纸桥最多 4 座；第 181 关起沿途灯火减为 1 盏、第 481 关起没有灯火；第 19–300 关只多 1 拍余量，第 301 关起含补给的总灯火恰好够走最短路，一步也不能多走。
- 23 枚主线邮票按累计星数解锁（最后一枚 1600 星）。邮票只是收藏，不改变解谜属性。

## 界面与操作

- 首页：开始/继续送信，以及"选关""邮票"两个入口。
- 选关：999关按章节连续纵向排列，支持惯性滑动和边缘回弹；进入时定位当前进度，「回到进度」可快速返回，轻触关卡直接开局。
- 邮票册：顶部固定收藏进度，三列卡片连续纵向滑动；支持惯性滚动、边缘回弹、滚轮和键盘滚动，卡片渐显、按压和下一枚高亮动效。
- 对局：顶部目标（剩余拍数、信笺、邮票），中间浮岛棋盘，底部当前局面提示、撤回与等一拍。点亮起的相邻格移动，点脚下格等一拍，点邮局建筑也能进入。
- 镜头固定为 2.5D 斜视角：双指捏合缩放 65%～160%，放大后单指或双指拖动平移；电脑滚轮缩放。进入关卡时浮岛在约 0.85 秒内由小变大。
- 操作引导仅在主线第一关对新玩家出现，可跳过并记住；第一关暂停菜单可重看。所有关卡的暂停菜单都有玩法说明。
- 失败后可免费重试、回看路线或（微信配置真实广告位后）看完整视频续灯一次。取消、异常、无填充、未配置均不发奖。
- 移动、收集、风推、纸桥、撤回、低灯火与结算使用差异化原创音效；背景音乐在前台播放，暂停、弹窗、广告和切后台时停止。

## 广告接入

`src/config.js` 中 `REWARDED_AD_UNIT_ID` 为空，需填入该小游戏账号下真实的激励式视频广告位 ID（AppID 不是广告位 ID），重新编译后在实体手机验收。只有 `onClose` 的 `res.isEnded === true` 才续灯，单局一次；并发和过期回调不会重复发奖。
