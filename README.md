## 开发环境自由选关

微信开发版（`envVersion === 'develop'`）与本机 `localhost` / `127.0.0.1` / IPv6回环地址的浏览器预览自动启用。选关页显示“开发环境”，999关均可点击；也可点“输入关卡号”，用数字面板或键盘输入1–999后开始试玩。

体验版、正式版、公网浏览器以及环境识别失败时均按正常通关进度解锁，不显示开发入口。开发进度和进行中路线使用独立存档，开发测试不会修改正式成绩。没有需要发布前手动关闭的配置开关，详见 [开发选关说明](docs/DEVELOPMENT-v8.md)。

## 玩法

- 每次有效移动或等待消耗 1 拍，撞墙不消耗，没有实时倒计时。
- 第 3 拍回声出现于起点，之后始终走在你三拍前的落点上；它只收蓝色邮票。
- 风格推动一次，最终落点记入轨迹；等待不触发风。灯格首次踏上补 3 拍，每盏一次。纸桥离开后碎裂，回声可通过。
- 信笺与邮票全收齐且到达邮局即胜；最后一点灯火抵达也算成功。
- 三星按关卡目标拍数评价，看广告续灯后最高二星。每程有 1～3 次撤回，越靠后越少。
- 难度分阶段上升，同一阶段内按最短路线由短到长排列：棋盘从 6×6 扩到 10×10，信笺与邮票最终各 6 枚，风口最多 4 处、一次性纸桥最多 4 座；第 181 关起沿途灯火减为 1 盏、第 481 关起没有灯火；第 19–300 关只多 1 拍余量，第 301 关起含补给的总灯火恰好够走最短路，一步也不能多走。
- 23 枚主线邮票按累计星数解锁（最后一枚 1600 星）。邮票只是收藏，不改变解谜属性。

## 界面与操作

- 首页：开始/继续送信，以及“选关”“邮票”“排行”入口。“排行”打开微信好友榜；“圈子”仅在微信开发版（develop）和体验版（trial）展示，使用配置的 openlink 打开微信游戏圈，微信版本不支持时显示提示。正式版、浏览器预览及无法识别版本的环境隐藏并禁用“圈子”。
- 选关：999关按章节连续纵向排列，支持惯性滑动和边缘回弹；进入时定位当前进度，「回到进度」可快速返回。进行中的关卡有明确标记，再次选择会接上原路线；需要重开时使用暂停菜单的“重新开始”。
- 邮票册：顶部固定收藏进度，三列卡片连续纵向滑动；支持惯性滚动、边缘回弹、滚轮和键盘滚动，卡片渐显、按压和下一枚高亮动效。
- 对局：顶部目标（剩余拍数、信笺、邮票），中间浮岛棋盘，底部当前局面提示、撤回与等一拍。点亮起的相邻格移动，点脚下格等一拍；也可直接点相邻格上的信封、邮票、风灯或邮局建筑，点击轮廓跟随物体的漂浮、摆动与镜头缩放。
- 镜头固定为 2.5D 斜视角：双指捏合缩放 65%～160%，放大后单指或双指拖动平移；电脑滚轮缩放。进入关卡时浮岛在约 0.85 秒内由小变大。
- 抵达动画中重复点击同一目标不会额外等待扣拍；明确点击“等一拍”仍然有效。开始缩放、拖动、取消触摸或改变窗口尺寸时，会取消尚未执行的排队动作。
- 收信、收票、补灯和通关会触发 260 毫秒的棋盘轻震，由 Canvas 镜头直接绘制，独立于手机的硬件振动能力。棋盘点击区域同步移动，按钮保持稳定；暂停、切后台、撤回或操作镜头时立即停止。
- 第一关操作引导分四步指出可点击的下一格：走过蓝票、继续前进、收信、进入邮局；通过真实的 3→2→1 次行动倒数解释回声收票。引导中误点人物、远格或等待不会扣拍，跳过后恢复自由操作；标题栏和暂停菜单可重新开启。撤回、重开、续玩会按实际状态更新提示，拍数不足时提示撤回或重新学习。所有关卡的暂停菜单都有玩法说明。
- 失败后可免费重试、回看路线或（微信配置真实广告位后）看完整视频续灯一次。取消、异常、无填充、未配置均不发奖。
- 局面提示使用真实剩余拍数和回声轨迹；到邮局后，只有原地等待确实能完成投递才提示等待。玩法说明展示当前关卡的星级拍数，选择续灯前明确说明最高二星。
- 存档写入暂时失败时保留最新内存进度，后续保存与切后台会尝试补存成绩、路线或待删除的旧路线；存储持续不可用时仍如实提示保存状态。
- 结算反馈：成功时信笺轻弹、纸屑散开，按实际成绩逐颗点亮星星；失败时灯火渐暗、余光散去。动效在约 1.2 秒内结束，弹窗按钮出现后即可操作；回看结果、切回前台与恢复存档不会重新播放结算动效。
- 移动、收集、风推、纸桥、撤回、低灯火与结算使用差异化原创音效；背景音乐为 32 秒的原创轻柔钢琴风格合成旋律，搭配分解和弦与柔和铺底，循环衔接。在前台播放，暂停、弹窗、广告和切后台时停止。

## 全局分享与转发

小游戏启动时统一启用微信右上角菜单的“发送给朋友”和“分享到朋友圈”，覆盖首页、选关、邮票册、对局与弹窗，不额外添加首页按钮。每次分享从 `src/config.js` 的 `SHARE_COVER_URLS` 三张指定封面中随机选择一张，好友／群转发与朋友圈共用这组封面，单次朋友圈分享的卡片和预览使用同一张图。标题统一为“风笺回廊｜和三拍后的回声一起送信”。

`src/sharing.js` 注册全局分享事件；分享打开后沿用游戏原有启动与本机进度逻辑，不传递成绩、不解锁关卡。浏览器预览不调用微信分享接口；微信端不支持朋友圈时保留普通转发。接口依据 [微信官方小游戏 API 定义](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts)，实际菜单能力由微信客户端决定。

## 排行榜

首页“排行”打开好友榜，展示微信好友的头像、昵称和成绩，按累计星数、通关数、总最佳拍数依次比较。成绩来自已有本地通关记录，旧存档可计入。玩家主动进入后，先完成微信隐私和公开头像昵称授权，再申请朋友信息授权；头像昵称接口使用 `withCredentials: false`，无需 `wx.login`。未授权时不上传好友成绩，仍可继续单人游玩。

好友信息、成绩查询与绘制均在开放数据域进行，由微信后台保存玩家托管的成绩摘要。更新前读取本人托管记录并保留更好的总成绩，再串行写入，避免较旧的本地存档覆盖更高记录。开发版同样能体验完整授权，使用 `wind_letter_rank_v1_development`；体验版和正式版使用 `wind_letter_rank_v1`。

用户已确认微信公众平台后台的隐私声明及统一隐私组件配置完成；代理因站点安全策略未独立核验后台，仍需通过微信内实际授权验证。微信会根据账号已有授权决定实际弹窗，不能保证每次固定出现五张提示，也不能替玩家设置微信游戏的“所有人可见”。浏览器预览不代替微信授权与双账号真机验收。

配置、计分、旧存档与真机验收见 [微信好友榜说明](docs/LEADERBOARD.md)。新版已取消世界榜，不再连接此前的云函数和数据库；已有云端历史资源和数据尚未删除。本机进度与进行中的路线仍保存在本地，好友榜不是跨设备续玩存档。

## 广告接入

`src/config.js` 中 `REWARDED_AD_UNIT_ID` 为空，需填入该小游戏账号下真实的激励式视频广告位 ID（AppID 不是广告位 ID），重新编译后在实体手机验收。只有 `onClose` 的 `res.isEnded === true` 才续灯，单局一次；并发和过期回调不会重复发奖。
