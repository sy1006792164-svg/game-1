# 风笺回廊

竖屏、单人、回合制的原生微信小游戏。送信员收集橙色信笺，晚三拍的回声沿历史落点收集蓝色邮票，最后到达邮局。首页直接开始或续玩，选关页集中提供5章30关主线、每日挑战及解锁后的高手路线；12枚邮票留作收藏。所有模式均可免费重试，进度保存在本机。

## 微信版直接运行

在微信开发者工具打开本目录 `E:\work\game-1`，项目类型为“小游戏”，点击“编译”。原微信项目直接使用本目录即可。`game.js` 直接加载 `src/main.js`，不需要 npm 安装、不需要构建、不需要数据库。

原飞机大战示例的 js/、images/、audio/ 已删除，新游戏只引用 src/ 和 assets/。原 project.private.config.json 保留。

## 浏览器验收

```powershell
cd E:\work\game-1
npm.cmd run preview
```

打开 http://127.0.0.1:8765 。方向键 / WASD 移动，空格等一拍，Esc 暂停；也可点击相邻格移动。预览与微信版共用规则和界面代码，两者的本地进度相互独立。

进入或续玩关卡时，浮岛会在约 0.85 秒内由小变大。手机双指捏合可缩放至 65%～160%，双指拖动平移场景；单指左右拖动连续旋转，上下拖动调整俯仰，直至上帝视角。电脑及微信开发者工具可按住鼠标拖动调整视角、滚轮缩放。角色通过点击亮起的相邻格移动，镜头操作不消耗拍数。

浏览器不显示广告测试入口；微信仅在配置真实广告位后显示可选续灯入口。原广告适配器的回调规则仍由自动测试覆盖。

## 玩法

- 每次有效移动或等待消耗1拍，撞墙不消耗，没有实时倒计时。
- 第3拍回声出现于起点，第4拍到达第1拍的最终落点；它只收蓝色邮票。
- 风格推动一次，最终落点记入轨迹；等待不重复触发风。
- 灯格首次触及补充3拍，每盏一次。
- 全收集且玩家到达绿色邮局即胜；最后一点能量抵达也算成功。
- 三星依关卡目标拍数评价；复活最高二星。邮票只作收藏，不改变属性。
- 每日挑战由本机日期生成，同一天固定；跨日重玩旧题仍记旧日期。离线版不做跨设备同步、防改时间或在线排名。

## 体验优化

- 首页保留一个开始/继续按钮，以及选关、邮票、设置三个入口；独立成长页、周目标展示和重复挑战卡已移除。
- 选关或每日入口直接开局。只有一条主线：20 章 120 关按顺序解锁，没有独立的高手模式。
- 对局围绕放大的浮岛棋盘，只保留目标、灯火、撤回和等待。直接点击亮起的相邻格移动，拖动棋盘调整视角，双指缩放和平移。
- 首关不再强制弹出全部规则；短提示依据当前目标和真实历史变化。地图仅保留回声轨迹与下一落点，坐标、预测表、方向键盘和实时星级门槛已移除。
- 动画期间最多缓存一个动作，暂停、撤回、切页和后台会清空。第4～6关删去无目标长支路，路口逐级为2、3、4个；目标、原解、最优步数和预算不变。
- 兼容原有本地成绩。内容版本 4 收紧了全部关卡的灯火预算，旧版进行中的路线会重新出发，已得成绩和邮票保留；旧的高手记录不再读取。昨日已开始的每日题仍按昨日记录。

早期设计记录见 [体验研究](docs/EXPERIENCE-RESEARCH.md) 与 [体验优化 v3](docs/EXPERIENCE-v3.md)；其中成长页、周目标和密集对局信息已由上述简化流程替代。
