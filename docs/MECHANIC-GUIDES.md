# 首次道具 / 机关指引

新增机制复用第一关的两步说明卡、场景高亮、手指和按钮提示。介绍的是本关实际出现的道具；观察时不调用规则引擎、不移动角色、不扣拍、不消耗撤回、不改变收集或纸桥状态。认识规则后由玩家自行规划路线，避免后期原预算关卡因教学强制绕路而变得不可过。

| 机制 | 顺序游玩首次出现 | 展示的规则 |
| --- | --- | --- |
| 风口 | 13 关 | 点击相邻箭头格后额外推动一次，虚线连接实际落点，只扣一拍；不会连吹，等待不触发，前方不通时不推；收集看最终落点。 |
| 纸桥 | 16 关 | 可以踏上，离开后才碎；不能返回，回声仍按历史脚印通过。 |
| 风灯 | 19 关 | 走到灯格，正常移动扣一拍后补三拍；每盏只能补一次。 |

进入含未认识机制的关卡时自动打开。先点击手指指向的物件或“看看规则”，第二步展示操作后果；再点“开始投递”恢复原控制。一个关卡含多种未认识机制时逐个介绍。“跳过”只关闭当前种类，未认识的下一种仍显示。观察期间误点、方向键、等待和撤回不会消耗拍数。

## 存档与回看

- `profile.mechanicGuides` 仅接受 `wind`、`bridge`、`light` 的布尔值；完成或显式跳过一种后保存，与首关 `guideDismissed` 独立。不能用通关数推断已读，旧档及开发跳关也能看到遗漏的说明。
- `run.mechanicGuide` 只保存当前种类、观察阶段和是否手动回看，不保存或注入模拟棋局。恢复时由当前真实地图和已确认种类重新建立队列。正在看的第二步可以在重开应用后继续。
- 重试会重新开始尚未确认的说明；已确认的不会反复出现。撤回只回退棋局，已认识的规则不会遗忘。暂停及回到前台保留正在看的阶段。
- “操作引导”可从关卡顶部和暂停菜单重新打开本关全部机制。手动回看不清除既有知识、不重置棋局，并可保存当前种类/阶段后继续。
- 旧档如果已收灯或踏碎桥，优先高亮仍可使用的物件；若已全部使用，会明确说明已经使用/已经碎裂，不暗示能重复领取。
- 正式和开发存档仍分开保存；清空游戏进度同时清空已认识机制。

## 验证

`tests/mechanic-guide.test.js` 验证机制种类、引擎实际风后落点、被挡住的风、已使用灯/桥、存档白名单与失败重试。

`tests/integration.test.js` 在真实 `Game` 流程中覆盖小屏场景点击、误点与等待/撤回、跳过队列、重试、旧档、恢复、后台暂停、手动回看后撤回。已有全 999 关通关测试开启机制指引，确认只在第 13、16、19 关首次弹出，观察前后棋局完全相同；随后原路线全部得到三星，不续灯、不增加撤回或步数。

场景观察目标具有单元格语义，先按下后重绘仍按同一目标确认。高亮格上的教学命中仅在观察期间覆盖相邻物件；正式玩法保持正常格子/道具命中规则。
