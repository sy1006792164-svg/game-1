# 开发环境自由选关（1.8.0）

更新日期：2026-09-08。主线内容版本保持5。

## 使用方式

开发环境打开“选关”，会看到“开发环境 · 全关卡自由试玩”。直接点任意关卡即可开始；“输入关卡号”提供数字键盘，可输入1–999，也支持电脑数字键、退格、Enter确认和Escape取消。0、1000、空输入、非整数不会启动关卡。

对局标题下显示“开发试玩 · 独立存档”。正常操作、关卡规则、星级与续玩机制照常运行。

## 环境边界

| 运行环境 | 自由选关 |
|---|---|
| 微信账号信息明确返回 `miniProgram.envVersion === 'develop'` | 开启 |
| 微信 `trial` 体验版 | 关闭 |
| 微信 `release` 正式版 | 关闭 |
| 微信接口缺失、抛错、版本字段缺失或未知 | 关闭 |
| 浏览器HTTP/HTTPS本机回环：localhost、127.0.0.1、::1 | 开启 |
| 公网、局域网浏览器、file协议、未知地址 | 关闭 |

微信版本标识使用官方小游戏类型定义中的开发/体验/正式枚举，接口通过`wx.getAccountInfoSync()`读取。[微信官方小游戏API类型定义](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts)

微信环境不会降级套用浏览器地址判断，即使工具窗口具有localhost地址也不例外。`enableDebug`、设备名称、网址查询参数和存档字段均不作为开启依据。没有发布前需要手动关闭的开关。开发入口的显示、输入处理和选关入口均检查开发权限；无效或未解锁的正式关卡仍会被选关入口拒绝。

## 存档隔离

正式环境继续使用`minigame.local.profile.v1`及`minigame.local.run.v1`。

开发环境使用`minigame.development.profile.v1`及`minigame.development.run.v1`，不读取、复制或修改正式成绩和路线。开发跳关通关后，正式环境不会因此解锁后续关卡。开发和正式存档的清理操作也分别作用于各自的数据。
