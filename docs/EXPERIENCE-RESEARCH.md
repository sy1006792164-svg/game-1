# 风笺回廊：体验、难度与回访设计参考

检索日期：2026-09-07。研究对象是本项目的 6×6 回合制解谜：玩家收信、固定晚三拍的回声盖章、风改变最终落点、灯提供有限补给。已阅读 README.md 与 docs/RESEARCH.md。本文件记录设计依据与验收建议，功能是否完成应以代码、测试和验收记录为准。

## 本项目建议

### 1. 难度增加来自可理解的路线决策

保留开头对移动、等待、回声的短教学，后续逐步加入分支回访、远端目标、风后落点和灯的经过顺序。高手模式在玩家主动选择后收紧容错，入口写清“更少余量，挑战更短路线”。所有模式保留相同的目标说明和回声预览。

每关保留可执行的参考解，并用真实引擎从起点逐步回放验证。灯带来的总能量不能只做终局加减，必须验证每个中间回合都有足够能量走到补给。参考解拍数可以作为设计目标；没有最短路径证明时，不在界面称为“理论最优”。关卡变化后以内容版本区分成绩，避免旧关成绩被拿来比较新地图。

### 2. 把三拍回声变成看得懂的规划工具

棋盘附近放置“下一拍”和随后两拍的回声队列，尚未出现时说明还需等待几拍；重叠的格子需要保持标记可辨。预览跟随最终落点历史，必须覆盖风推动、原地等待、撞墙不耗拍等情况。

顶部优先保留本关目标、剩余拍数和当前已走拍数。目标全收齐后提示改为“现在回到邮局”，不要继续显示无关的收集指导。暂停后恢复时这些信息仍可见。规则提示、收集反馈与装饰动画分层，减少文字遮挡棋盘。

### 3. 失败后知道如何改善，并能马上再试

失败结算展示本局已完成多少收集、还缺什么及一条与状态有关的提示。例如：“邮票已齐，还差 1 封信”比笼统的失败文案更有指导性。成功结算展示本局拍数、个人最好和本次改善幅度，鼓励优化路线。

“免费重试”保留为容易找到的操作。广告续灯作为自愿选择，失败、无填充或未配置广告不能阻断重试。模式、地图版本、使用续灯与否应有明确记录口径；普通与高手最好成绩独立保存。较差成绩不能覆盖较好成绩。

### 4. 回访理由清楚，允许玩家按自己的节奏回来

首页用一处固定入口展示今日挑战状态及下一项收藏目标，点击后直接进入对应内容。每日题同一天保持一致，重试才具有改进路线的意义；完成后可以继续追逐个人纪录。

周目标采用累计进度，例如本周完成若干个不同日期的每日题，允许不连续参与。断一天不清空已经获得的邮票、等级或永久收藏。具体目标数量要经试玩调整。这个“非惩罚式周目标”是本项目选择，不是上述来源已验证有效的结论。

收藏解锁应同时覆盖首次通关、章节进展、每日完成和高手挑战，展示下一枚邮票的具体条件与当前进度。收藏作为成长展示，不出售影响解谜公平性的属性。周目标的完成反馈可以轻量显示，不额外阻断下一局。

离线版按本机日期分配每日与每周进度；本地时间可变、存档不跨设备，不能宣传为可信的全球竞赛。跨午夜恢复旧挑战时成绩仍归属于原题日期，周边界与日期跳转需有确定规则。

## 建议验收指标

以下是建议测量项和功能判定方法，不是当前测试结果，也不是已经取得的提升数据。

| 目标 | 建议验收与观察方法 |
| --- | --- |
| 难度确实增加且可解 | 全部标准与高手关卡参考解经引擎回放通关，记录目标拍数、初始能量、补给与剩余余量。每日题选取连续日期及跨年边界批量回放。记录各章节首次通关尝试次数分布，排查突然陡升的关卡。 |
| 目标与回声可理解 | 让新玩家在不口头提示的情况下描述三个胜利条件、预测下一拍回声落点；记录错误集中在哪种状态。检查等待、风口及回声尚未出现的边界。 |
| 触摸体验可靠 | 小屏幕与安全区设备上，文字、棋盘、按钮不相互遮挡，按钮可独立命中。方向键、点击相邻格、滑动与等待具有一致结果。 |
| 失败可复盘 | 失败文案准确反映尚未收集项目；一次操作即可免费重试同一题，重新开始时状态干净。记录失败后重试率、重试前停留时间与退出原因。 |
| 成长记录准确 | 标准与高手成绩隔离；只更新更好纪录；重复完成同一天不重复增加“不同日期”计数；进度保存后重开应用一致。 |
| 周目标无惩罚 | 隔天参与仍累计本周进度；跨周只切换当前周进度，已得收藏保留；日期跳转不会重复领取同一永久收藏。 |
| 回访是否改善 | 在取得合适的真实试玩样本后比较每日题参与率、不同日期再次游玩人数、D1/D7 回访、每次会话主动重试次数，同时查看反馈中的疲劳和挫败。明确样本数、版本、观察期和分母，避免把单次界面测试当作留存证据。 |

离线工程的自动测试只能验证规则和记录是否正确，不能验证真实用户黏性。是否更愿意回来，应由实际试玩与持续观察判断；本轮不承诺任何留存提升百分比。
