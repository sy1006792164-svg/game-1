# 启动页与健康游戏忠告

核对日期：2026-09-09。微信官方网页已通过直接 HTTP 读取正文；网页搜索工具未能读取正文时，未以转载文章代替官方规则。

## 官方要求

- [微信小游戏运营规范](https://developers.weixin.qq.com/minigame/product/)“小游戏规范 → 2.6 信息标识”的 2.6.2 要求在游戏开始前，于画面显著位置全文登载《健康游戏忠告》。2.6.1 要求忠告之后、游戏开始前设置专门页面，展示经批准的著作权人、出版服务单位、批准文号、出版物号等信息。
- [官方封面图插件文档](https://developers.weixin.qq.com/minigame/dev/guide/performance/perf-action-start-loading-plugin.html)把首包绘制简单静态图列为启动优化实践，并提供静态图、多图切换、进度条等模板。因此动画和百分比条并非统一强制形式。上述文档没有规定忠告必须停留几秒；本次按用户要求使用准备进度条和自动进入流程，文中所述平滑过渡和出版信息停留时长是本项目的体验设置。
- [微信适龄提示指引](https://developers.weixin.qq.com/minigame/introduction/guide/slts.html)要求在“微信公众平台 → 设置 → 基础设置 → 基本信息 → 适龄提示”设置并提交审核。审核通过后，平台统一在启动页展示官方标记；即便游戏内自行展示，仍须配置平台信息。用户本次明确确认等级为 **8+**；仅此确认不等于已核实后台审核状态。

## 实现与配置

每次冷启动显示名称、山间邮路场景、健康忠告标题和全部四句正文，下方显示进度条、整数百分比与当前准备阶段。依次完成本地进度读取、续玩路线读取、邮票册整理和首页准备；完成后自动进入首页，无需点击“进入回廊”。场景沿用原创 Canvas 图形，轻柔动效无需图片下载。启动期间不播放音乐、不开始对局；进入首页后沿用原来的开始／续玩逻辑。

品牌大标题使用随包提供的宋体矢量轮廓，与主页共用绘制逻辑，避免手机缺少指定系统字体时回退为默认字形。来源与复测说明见 [标题字形说明](TITLE-TYPOGRAPHY.md)。

健康忠告内容在 `src/startup.js` 集中维护；视图在 `src/startup-view.js`。百分比根据实际已完成的准备任务数计算，900 毫秒的视觉平滑过程不会越过已完成的任务进度；所有任务完成并显示 100% 后，短暂停留 180 毫秒再自动切页。该百分比表示本地启动准备进度，项目图形和关卡随包提供、音频按需加载，没有新增下载请求。此页面是游戏首帧后的启动展示，不替换微信客户端自身的代码包下载界面。

后台期间暂停推进自动切页计时，返回前台继续未完成流程；窗口调整不会跳过准备或重播已完成流程。出版信息展示期间若窗口尺寸变化，则从该信息的第一页重新计时，确保重新换行分页后的文字完整可见。准备失败时停留在启动页，在原进度区域显示“准备遇到问题，请重试”和“重新加载”，重试只重新执行失败任务，已完成的准备保持不变。正常加载期间没有可点击入口，防止点击穿透到首页。未增加平台授权请求、广告、联网资源或存档字段。

为继续满足项目原有 2 MiB 源码及素材预算，删除无调用的旧 `collect.wav` 及其生成／注册项（25,622 字节）。现有收信与收票使用独立的 `letter`、`seal` 音效，所有实际使用的音频保持不变。

按用户要求，自绘启动页已移除“适龄提示 8+”文字及对应配置。用户确认的适龄等级仍为 `8+`，官方适龄配置、审核与标识展示由微信平台管理，不受本次移除影响。

`PUBLICATION_INFO` 对应四项真实资料：

| 字段 | 内容 |
| --- | --- |
| `copyrightHolder` | 著作权人 |
| `publisher` | 出版服务单位 |
| `approvalNumber` | 批准文号 |
| `publicationNumber` | 出版物号（ISBN） |

有内容时，在健康忠告之后显示独立出版信息页，每页在前台展示 2,500 毫秒后自动翻页，最后一页结束后自动进入首页；没有上下页或进入按钮。长字段完整换行，超过可见区域时分页，保留全部文字；多页时显示页码。空字段不展示；四项全空时直接进入首页。所有字段目前留空，因为用户尚未提供本游戏真实资料，不能把参考截图中其他游戏的公司、版号或 ISBN 填入本项目。配置接口就绪不代表出版资料已齐全，也不代表游戏已经具备提审资质。发布前应按照该账号适用流程补齐真实资料并核对后台要求。
