# 风笺回廊：体验优化 v3

日期：2026-09-07。应用版本：1.2.0。项目目录：`E:\work\game-1`。本轮围绕清楚目标、可选的更高难度和持续成长改进页面与流程。公开依据及适用推论见 [体验研究](EXPERIENCE-RESEARCH.md)。

## 已落地设计

| 部分 | 当前行为 |
| --- | --- |
| 标准与高手 | 保留5章30关标准邮路。主线前三关完成后开放高手入口，对应标准关完成后才能挑战该关高手。30条高手邮路比标准少2～5拍初始灯火，参考解完成时余1拍；高手不使用续灯，成绩存入独立的 `expert` 记录。参考解拍数是设计目标，不宣称理论最短。 |
| 首页与成长 | 首页展示成长等级、下一枚邮票、每日与高手入口。成长页展示晋级进度、本周任选3天完成每日题的进度，以及可直接进入的后续关卡、三星或高手建议。 |
| 回声与目标 | 棋盘展示未来3拍回声的编号位置，收集目标区分玩家信笺和回声邮票；低能量时给出提示。玩法仍按有效移动或等待推进，没有实时倒计时。 |
| 失败与结算 | 失败弹窗以免费重试为主操作，并提供路线复盘和剩余目标提示。成功结算展示个人最佳及成长反馈；已得星星与收藏不会因失败减少。 |
| 日期与存档 | 兼容原有 `version: 1` 成绩并补充高手记录。每日题以开始该局的日期结算，跨日继续或重试旧题仍记旧日；从今日入口新开局时重新取本机当天日期。周目标按不同日期累计，无需连续签到。 |

成长等级由主线星星和高手完成情况形成，收藏邮票不改变角色属性。周目标提供回访提示，不扣除已得等级、星星或邮票。现有单局一次、自愿观看且完整观看才发奖的广告规则继续用于标准和每日模式；高手不续灯。

## 交付边界

真实广告位仍需在 `src/config.js` 配置；缺少广告位时 `release:check` 会失败。广告取消、加载失败、无填充或不可用时均不发奖，免费重试仍可用。真实广告接入、微信账号后台材料和审核结果仍按 [原验收记录](ACCEPTANCE.md) 的边界处理。

进度与每日题继续保存在本机，日期可被本机设置影响，不提供跨设备同步、防改时钟或在线排名。本轮没有真实用户留存实验结果，不宣称黏性、留存或收入已经提高，也不承诺提升百分比。
