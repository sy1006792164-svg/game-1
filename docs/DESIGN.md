# 风笺回廊 · 1.0 产品说明

玩家同时规划现在的行动和三拍前的轨迹。橙色信笺只由送信员收集，蓝色邮票只由回声收集；风改变最终落点，灯给出有限补给。把路线组织成恰好收齐两种物品、最终回到邮局的连续行动。

## 学习曲线与长期目标

没有倒计时或操作速度门槛，单局约半分钟至数分钟。前三关教授直行、转弯与取信顺序；第二章增加分岔和多物品；第13关开始风；第19关开始灯；最后六关组合使用。

- 30关按上关完成解锁，已完成关卡可以反复优化三星成绩。
- 12枚固定成长邮票提供可预期收集目标，不使用随机抽奖。
- 每日一条确定性离线路线，保存本机最佳成绩，无连续签到惩罚。
- 自动续玩降低中断成本，广告只在失败后自愿选择，不影响免费重开。

这些是留存设计假设，尚无商业留存数据。本版本没有联网埋点；上线前应邀请实际玩家观察首次理解率、第三关完成率和再次游玩意愿。

## 原创资源与架构

植物、旧纸、邮局与回声主题，森林绿为主色，信笺暖橙、回声雾蓝。角色、邮局、植物、棋盘和动效均为独立编写的Canvas几何；四组铃声为本地数学合成；512×512图标由项目脚本生成。不使用原飞机大战示例的素材。

原生JavaScript、Canvas 2D、CommonJS，无第三方运行依赖。微信直接运行，本地浏览器由脚本打包同一份代码。约30FPS绘制、140ms移动动画、DPR上限3，退后台停止绘制和声音。

两项本地缓存键保存进度，不建立账号或数据库。进行中的路线保存动作历史，恢复时重放规则校验；存储失败保留内存并提示。采用本机日期，不提供服务器反作弊、跨设备同步或在线排名。

## 复活

失败后可以自愿看一次完整视频，保留收集与轨迹并恢复 max(8,ceil(初始拍数/2)) 拍，最高二星。取消、异常、并发点击、重复/旧回调不发奖。浏览器仅提供明确标识的三分支测试面板，正式微信代码不会调用模拟奖励。

## 差异化与验收边界

差异化对比与检索范围见 RESEARCH.md。不能把未发现同名作品作为不存在相似作品的证明，也不能承诺微信必然过审。代码与本地运行可独立验收，实体手机、真实广告填充及后台审核须在实际账号环境完成。
