# 风笺回廊 · 1.8 产品说明

玩家同时规划现在的行动和三拍前的轨迹。橙色信笺只由送信员收集，蓝色邮票只由回声收集；风改变最终落点，灯给出有限补给。把路线组织成恰好收齐两种物品、最终回到邮局的连续行动。

## 学习曲线与长期目标

没有倒计时或操作速度门槛。前三关教授直行、转弯与取信顺序；第二章增加分岔和多物品；第13关开始风，第16关开始一次性纸桥，第19关开始灯。后续棋盘逐段扩大至10×10，信与票各增至6枚，纸桥增加至4座；第181关只剩一盏灯，第481关取消沿途灯火。第301关起含补给的总灯火只够最短路线，压力来自规划顺序与回声时机。

- 999关分为167章，最后一章3关；按上关完成解锁，已完成关卡可以反复优化三星成绩。同一关型阶段按最短路线长度排序，切换关型时加入新的路线约束。选关按章节分组连续上下滑动，进入时定位当前进度，取消章节翻页按钮；仅绘制可见区域内的关卡。
- 23枚主线纪念邮票按累计星数解锁，不使用随机抽奖。邮票册连续纵向滑动，进度区固定；更高的卡片为图案和标题留出间距，支持惯性、边缘回弹、卡片渐显与按压反馈。
- 自动续玩降低中断成本，广告只在失败后自愿选择，不影响免费重开。
- 开发环境允许任意选关或输入编号跳转，使用独立开发存档；体验和正式环境保留顺序解锁，开发功能由运行环境自动判定。

这些是留存设计假设，尚无商业留存数据。本版本没有联网埋点；上线前应邀请实际玩家观察首次理解率、第三关完成率和再次游玩意愿。

## 原创资源与架构

植物、旧纸、邮局与回声主题，森林绿为主色，信笺暖橙、回声雾蓝。角色、邮局、植物、棋盘和动效均为独立编写的Canvas几何；音效和背景音乐为本地数学合成；512×512图标由项目脚本生成。不使用原飞机大战示例的素材。

原生JavaScript、Canvas 2D、CommonJS，无第三方运行依赖。微信直接运行，本地浏览器由脚本打包同一份代码。约30FPS绘制、140ms移动动画、DPR上限3，退后台停止绘制和声音。

两项本地缓存键保存进度，不建立账号或数据库。进行中的路线保存动作历史，恢复时重放规则校验；存储失败保留内存并提示。每日关卡功能已移除。历史每日成绩仅作为兼容数据保留，旧每日进行中存档不再恢复；主线进度正常续玩。不提供跨设备同步或在线排名。

## 复活

失败后可以自愿看一次完整视频，保留收集与轨迹并恢复 max(8,ceil(初始拍数/2)) 拍，最高二星。取消、异常、并发点击、重复/旧回调不发奖。浏览器预览不出现广告按钮；微信内配置真实广告位后才显示续灯入口。

## 差异化与验收边界

差异化对比与检索范围见 RESEARCH.md。不能把未发现同名作品作为不存在相似作品的证明，也不能承诺微信必然过审。代码与本地运行可独立验收，实体手机、真实广告填充及后台审核须在实际账号环境完成。
