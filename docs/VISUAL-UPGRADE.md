# 晨雾邮路：画面与操作体验更新

2026-09-09。方向：精致立体、治愈解谜。

本轮对照了 [ustwo 的《Monument Valley 3》官方展示](https://ustwogames.co.uk/our-games/monument-valley-3/)，并实际查看本项目首页、对局、引导和结算。建筑的体块层次、明度分离与场景留白是本项目据此采用的设计方向；没有使用对方的图片、角色或关卡。

## 实际改动

- 文字明确的主按钮采用居中文字：清理首页/排行“继续送信”的小信封和尾箭头，以及通关、暂停、确认、返回、授权、教学跳过和开发选关中的同类装饰。撤回、等待、暂停、导航与关卡目标图标保留；按钮内容按可见正面垂直居中。
- 世界从整屏深绿改为奶油晨空、鼠尾草远山、柔和雾与少量浮尘。象牙石板、珊瑚屋顶和青蓝回声有不同的明度与颜色。
- 首页重新绘制高塔邮局、三连拱廊、露台、台阶、水池、庭园和统一方向的阴影；标题、出发信息与主按钮重新编排，保留开始/继续、选关、邮票、排行与原游戏圈显示条件。
- 实际棋盘同步增加石板倒角、分层砌石地台、圆润树木和新的邮局材质。首页和对局共用重新绘制的送信员与回声，所有画面均由本地 Canvas 绘制，不依赖网络图片。
- 拍数 HUD 加入灯火大读数、独立收集图标、真实进度刻度与完成反馈；教学改为纸签，移除割裂场景的矩形灰罩，保留局部光晕、箭头和手指提示。
- 全部菜单、邮票、按钮、弹窗与原生好友榜统一浅纸配色，成功和失败采用邮戳回执。原生头像昵称授权按钮也与主按钮配色一致，授权行为未改。
- 微信端在移动、入场、镜头操作和按住触控期间请求 60 FPS 并绘制每次 RAF；静止和普通暂停回到 30 FPS。没有缩短行动动画、放宽输入缓冲或改变动作执行时刻。这里是绘制策略，实际设备帧率仍需真机测量。

## 验证

- `npm.cmd test`：256 项通过，0 失败，0 跳过。新增测试覆盖入场/移动/静止帧率，以及缓冲动作仍在原 `MOVE_MS` 边界执行、暂停后不改变路线和能量。
- `npm.cmd run verify:levels`：999/999 关通过；59,240 步合法行动，原灯火预算、无续命。集成测试还覆盖从空存档连续通关到第 999 关的运行流程。
- `src/engine.js`、`src/levels.js`、`src/levels-extra.js` 的 SHA-256 与改动前一致。关卡数据、预算、三星条件和撤回次数没有改变。
- `npm.cmd run check` 与 `npm.cmd run build` 通过；源代码和素材仍在项目 2 MiB 预算内。
- 浏览器实测：390×844 首关逐格点击、收信、回声收票与投递；320×568 首页、选关滚动、第 999 关缩放、失败回执及一次点击免费重试；430×932 邮票册。自动测试同时覆盖全部关卡的小屏/平板绘制与道具命中。
- 浏览器预览与微信共用渲染和规则代码。本轮未执行微信真机性能测试或真实广告验收。
