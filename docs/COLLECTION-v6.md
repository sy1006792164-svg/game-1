# 邮票册与主线界面更新（1.6.0）

更新日期：2026-09-08。主线仍为999关，关卡内容版本仍为5，本次界面更新不会重开正在进行的主线关卡。

## 邮票册

- 取消页码与翻页按钮，23枚主线纪念邮票连续纵向排列。
- 保留三列，卡片加高、图案放大，拉开编号、状态、图案、名称与星数的间距。最后两枚居中收尾。
- 标题、收藏总数和下一枚进度固定在顶部；卡片列表裁切在独立区域内，底部自然露出下一行。
- 手指拖动与鼠标拖动同步跟随，松手后惯性减速，边缘带阻力并回弹；轻触可停止惯性，不会误触邮票。
- 支持滚轮、方向键、PageUp/PageDown、Home/End。滚动条在滚动时出现，停止后淡出。
- 卡片进入可见区域时渐显上浮，按下轻微缩小，点击后回弹；下一枚邮票有柔和的环绕光点。
- 裁切区域外的卡片不响应点击；切换页面、窗口变化、退后台和触摸取消会终止当前手势。

## 移除每日一关

选关页每日入口、每日地图生成、日期刷新、每日模式启动/恢复、每日专属邮票及对应文案均已移除。旧每日进行中存档不再恢复，首页继续进入主线。已有主线成绩正常保留与续玩；历史每日成绩仅作为存档兼容数据保留，不再产生新成绩，也不参与邮票解锁。

## 验证

- `npm.cmd test`：119项通过，0失败、0跳过，包含999关主线回放与既有对局回归。
- 滚动专项覆盖惯性、两端回弹、轻触/拖动区分、暂停后释放不甩动、连续滚轮、窗口边界变化和裁切区域外误触。
- 模式移除回归覆盖旧每日存档退出、新每日成绩拒绝写入、主线继续游玩，以及不存在每日入口和邮票分页按钮。
- 浏览器390×844、320×568验证了空收藏和21星/4枚收藏状态、连续拖动、滚轮到底、最后两枚居中与固定顶部；没有浏览器运行错误。
- 构建与源码/资源检查通过。此次没有重新进行微信真机触摸测试。

主要代码：`src/collection-view.js`、`src/list-scroll.js`、`src/main.js`、`src/platform.js`、`src/stamp-album.js`。1.7版本将滚动模块更名为`list-scroll.js`，供选关列表与邮票册共用。
