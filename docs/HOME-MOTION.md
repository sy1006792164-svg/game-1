# 加载页与主页动效 v1.9.1

更新日期：2026-09-10。用户提供的 v1.9.0 真机截图已经显示固定宋体标题；本次继续增加两页的柔和动效。

## 表现

- 信笺和邮票各自轻轻漂浮，回声上下浮动并缓慢变化透明度。
- 人物以脚下固定位置为基准轻微呼吸，邮局小旗随风摆动，水纹与远处小鸟轻动。
- 主页开始／继续按钮外有柔和呼吸光，按钮自身的位置、文字、尺寸与命中区域保持固定。
- 加载条的扫光裁剪在实际已加载的区域内，不改变进度，不延长加载；所有任务完成后仍自动进入主页。

修改仅位于 `drawVignette`、首页专用的 `drawHomeArchitecture` 和两页的装饰绘制。关卡棋盘、格子命中、道具教学、规则与难度未修改。没有新增图片、音频、联网请求或计时器，使用原渲染循环；切后台仍停止绘制。现有减少动态标记开启时，这些动效静止或关闭。
