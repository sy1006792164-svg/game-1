## 持续检查

```powershell
npm.cmd run verify:levels
npm.cmd test
npm.cmd run check
npm.cmd run build
```

`verify:levels` 检查全部 999 关，并生成 `work/solvability-report.json`：逐关保存可回放的路线、原始预算、目标拍数、实际拍数、剩余灯火、收集和机关事件，以及关卡数据和源码的 SHA256。路线编码为 U 上、D 下、L 左、R 右、W 等一拍。

`check`、`release:check` 和浏览器构建均接入同一个全量验证门禁。任何关卡缺少合法获胜路线、撞墙、提前耗尽灯火、未收齐目标或无法达到原三星目标，检查都会失败；验证器不会调整预算或跳过非法动作。失败表示该关尚未通过通关证明，不能直接等同于已经穷尽所有方案并证明无解。

新增回归还刻意破坏路线、缩减预算、加入不可达目标、漏关及重复编号，验证检查能拒绝这些情况。完整主流程测试通过真实 `Game.act` 和结算按钮连续推进全部关卡，覆盖进度解锁、末关结束和存档恢复。

本次独立规则审计脚本及逐关结果保存在 `work/independent-solvability.js`、`work/independent-solvability.json`，不进入游戏包。
